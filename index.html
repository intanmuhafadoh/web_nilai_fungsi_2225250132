01 - MATERI

Mengenal Nilai Fungsi

Nilai fungsi adalah hasil yang diperoleh ketika suatu bilangan dimasukkan ke dalam fungsi dengan menggantikan variabel yang tersedia.

1. Pengertian Fungsi

Fungsi merupakan aturan yang memasangkan setiap anggota suatu himpunan dengan tepat satu anggota himpunan lainnya. Dalam fungsi, setiap nilai masukan hanya memiliki satu nilai keluaran.

2. Notasi dan Bentuk Fungsi

Fungsi biasanya dituliskan menggunakan notasi f(x). Salah satu bentuk fungsi yang sederhana adalah:

f(x) = ax + b

Keterangan:

  • f = nama fungsi
  • x = variabel atau nilai masukan
  • a = koefisien variabel
  • b = konstanta
  • f(x) = nilai keluaran fungsi

Contoh:

f(x) = 2x + 3

Artinya, setiap nilai x dikalikan 2, kemudian ditambah 3.

3. Domain, Kodomain, dan Range

Dalam suatu fungsi terdapat tiga istilah penting:

  • Domain: himpunan semua nilai masukan.
  • Kodomain: himpunan tujuan nilai keluaran.
  • Range: himpunan nilai keluaran yang benar-benar dihasilkan.

Contoh:

f(x) = 2x

Domain = {1, 2, 3}
Kodomain = {2, 4, 6, 8}
Range = {2, 4, 6}

4. Cara Menentukan Nilai Fungsi

Untuk menentukan nilai fungsi, kita mengganti variabel x dengan bilangan yang diketahui. Proses ini disebut substitusi.

Langkah-langkah:

  1. Tuliskan fungsi yang diketahui.
  2. Tentukan nilai x yang akan dimasukkan.
  3. Ganti variabel x dengan nilai tersebut.
  4. Lakukan operasi hitung.
  5. Tuliskan hasil akhirnya.

Contoh soal:

Diketahui f(x) = 2x + 3. Tentukan f(4)!

f(4) = 2(4) + 3
f(4) = 8 + 3
f(4) = 11

Jadi, nilai fungsi f(4) adalah 11.

5. Menentukan Nilai Fungsi dalam Tabel

Nilai fungsi juga dapat disajikan dalam bentuk tabel agar hubungan antara nilai masukan dan keluaran lebih mudah dipahami.

Contoh: Diketahui f(x) = 2x + 1. Tentukan nilai fungsi untuk x = 1, 2, 3, dan 4.

x Perhitungan f(x)
1 2(1) + 1 3
2 2(2) + 1 5
3 2(3) + 1 7
4 2(4) + 1 9

6. Penyajian Fungsi

Fungsi dapat disajikan dalam beberapa bentuk:

  • Diagram panah: menunjukkan hubungan antara anggota domain dan kodomain.
  • Tabel: menunjukkan pasangan nilai masukan dan keluaran.
  • Rumus fungsi: menunjukkan aturan untuk memperoleh nilai keluaran.

7. Penerapan Fungsi dalam Kehidupan Sehari-hari

Fungsi dapat digunakan untuk menghitung biaya, menentukan harga barang, dan menyelesaikan berbagai permasalahan sehari-hari.

Contoh soal:

Harga satu buku adalah Rp4.000 dan biaya bungkus sebesar Rp2.000. Jika x menyatakan jumlah buku, tentukan biaya untuk membeli 3 buku!

f(x) = 4000x + 2000
f(3) = 4000(3) + 2000
f(3) = 12000 + 2000
f(3) = 14000

Jadi, biaya untuk membeli 3 buku adalah Rp14.000.

8. Kesalahan yang Harus Dihindari

  • Tidak mengganti semua variabel x dengan nilai yang diketahui.
  • Menganggap f(4) berarti f dikalikan 4.
  • Keliru membedakan perkalian dan penjumlahan.
  • Tidak memperhatikan tanda positif dan negatif.
  • Tidak mengikuti urutan operasi hitung.

Ingat! f(4) berarti nilai fungsi ketika x = 4, bukan f dikalikan 4.

02 - CONTOH

Yuk, Pahami Contohnya!

Diketahui:

f(x) = 2x + 3

Tentukan nilai f(4)!

Langkah 1. Ganti x dengan 4.

Langkah 2. f(4) = 2(4) + 3

Langkah 3. f(4) = 8 + 3

Langkah 4. f(4) = 11

Jadi, nilai f(4) adalah 11.
